### 🎟️ [Convoca](https://github.com/BorjaZG/Convoca)

**Full-stack event management platform**

A complete platform for managing local cultural events, allowing organizers to publish events and users to discover and reserve tickets.

**Highlights**

* Full-stack monorepo architecture
* REST API with authentication and role-based authorization
* Event management and ticket reservations
* PostgreSQL database with Prisma ORM
* Cloudinary integration for image management
* Shared TypeScript types between frontend and backend
* **66 automated tests**
* Docker-based development environment

**Stack:** `Node.js` · `Express` · `TypeScript` · `React` · `PostgreSQL` · `Prisma` · `Docker` · `Tailwind CSS` · `Vitest`
